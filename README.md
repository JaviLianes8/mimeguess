# mimeguess

Deterministic, OS-independent file extension and MIME type mapping generated
from mime-db, zero dependencies.

## Install

```
pip install mimeguess
```

## Usage

```python
import mimeguess

mimeguess.guess_type("report.pdf")        # "application/pdf"
mimeguess.guess_type("PHOTO.JPG")         # "image/jpeg"
mimeguess.guess_type("backup.tar.gz")     # "application/gzip"
mimeguess.guess_type("Makefile")          # None

mimeguess.guess_extension("image/png")                 # ".png"
mimeguess.guess_extension("text/html; charset=utf-8")  # ".html"
mimeguess.extensions_for("image/jpeg")                 # (".jpg", ".jpeg", ".jpe")

mimeguess.guess("site.tar.gz")
# Guess(type='application/x-tar', encoding='gzip', extension='tar')
mimeguess.content_type_for("index.html")  # "text/html; charset=utf-8"
mimeguess.media_type_info("application/ld+json")
# MediaTypeInfo(type='application/ld+json', source='iana', extensions=('.jsonld',),
#               charset=None, compressible=True, suffix='json')

mimeguess.structured_suffix("image/svg+xml")   # "xml"
mimeguess.essence("Text/HTML; charset=UTF-8")  # "text/html"
mimeguess.sniff(b"%PDF-1.7 ...")               # "application/pdf"

# Your own mappings, without touching global state.
table = mimeguess.default_table().with_types({"text/x-typescript": ["ts", "d.ts"]})
table.guess_type("index.d.ts")                 # "text/x-typescript"
```

Lookups are case insensitive and ignore parameters on a MIME type. Unknown or
malformed input gives `None` (or an empty tuple); only `essence()` raises, with
`InvalidMediaType`, a `ValueError`.

## Command line

```
mimeguess type report.pdf               # application/pdf
mimeguess type site.tar.gz --encoding   # application/x-tar<TAB>gzip
mimeguess ext image/jpeg                # .jpg .jpeg .jpe
mimeguess info application/json
mimeguess sniff download.bin
mimeguess source
```

## Where the data comes from

The table is generated by a committed script from a committed snapshot of
[jshttp mime-db](https://github.com/jshttp/mime-db) 1.54.0 (MIT), which merges
the IANA Media Types registry, Apache httpd and nginx. Extension conflicts are
resolved exactly like jshttp mime-types 3.0.2. A short, labelled, hand-written
supplement keeps a few extensions mime-db does not list. Call
`mimeguess.data_source()` for the version, URL, checksum and license. The
[GUIDE](GUIDE.md) has the full policy and the measured differences from the
standard library.

## Why

The standard library `mimetypes` reads the host's files and, on Windows, the
registry, so the same call can return different answers on different machines;
even `mimetypes.init(files=[])` still reads them. Its built-in table also changes
between Python versions and holds about 150 to 200 entries. Content sniffers
such as `python-magic` need the native `libmagic` library, and `filetype` or
`puremagic` inspect bytes rather than map names. `mimeguess` ships a fixed table
of 2,500+ types and 1,200+ extensions inside the package: the result depends
only on the input, never on the operating system, and there is nothing to
install beyond the wheel.
